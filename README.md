## 🧠 Featured Work

**[Amirkabir-Assistant](https://github.com/MH-2005/Amirkabir-Assistant)** — A RAG-based chatbot that answers student questions about university rules and regulations. Documents are embedded with Sentence Transformers, stored in ChromaDB, and retrieved via semantic search to ground answers generated by the Gemini API.
`Python` `RAG` `ChromaDB` `Sentence Transformers` `Gemini API`

**Mine Traceability Management System** — An enterprise backend for managing and tracking a mineral supply chain (mining site → depot → gathering point → warehouse → funnel → jumbobag), built during my work as a backend developer. Clean layered architecture with the DAO pattern, AES-encrypted logs, OpenAPI 3.0 documentation, and Docker-based deployment.
`Java` `Spring Boot` `PostgreSQL/PostGIS` `DAO` `AES` `OpenAPI 3.0` `Docker`
